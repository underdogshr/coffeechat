# 폰트 이용허락문

키트에 들어 있는 woff2 폰트 파일은 수정하지 않았습니다. HTML을 패키지로 재배포할 때 사용한 폰트와 해당 이용허락문을 함께 포함하세요.

- Montserrat: `Montserrat-OFL.txt`. [Google Fonts의 공식 배포 원문](https://raw.githubusercontent.com/google/fonts/main/ofl/montserrat/OFL.txt). woff2는 Google Fonts 파일을 재배포하는 [Fontsource @fontsource/montserrat 5.2.5](https://www.npmjs.com/package/@fontsource/montserrat)의 기본 라틴 4개(예: `Montserrat-Regular.woff2`)·확장 라틴 4개(예: `Montserrat-Regular-LatinExt.woff2`) 파일을 이름만 바꿔 넣었습니다.
- Pretendard JP: `PretendardJP-OFL.txt`. [공식 저장소 LICENSE](https://raw.githubusercontent.com/orioncactus/pretendard/main/LICENSE) 원문 그대로입니다(SIL OFL 1.1, 예약 글꼴 이름 'Pretendard'). woff2는 Pretendard JP v1.309(1.3.9) OTF의 Regular·Bold를 fontTools로 WOFF2 압축만 한 것입니다. 원본 OTF와 표(table) 단위로 대조해 모든 표가 바이트 단위로 같고, WOFF2 규격상 바뀌는 `head` 표의 압축 표시(flags 11번 비트)와 체크섬만 다르며, WOFF 메타데이터는 넣지 않았습니다. [OFL FAQ 2.2.1](https://openfontlicense.org/ofl-faq/)의 조건(원본 데이터는 WOFF 압축 외 변경 없음, 메타데이터 생략)에 해당하므로 수정본이 아니어서 이름을 그대로 씁니다.
- NanumHuman: `NanumHuman-OFL.txt`. 폰트 내부의 2019 NAVER / Sandoll 저작권 고지, [네이버 나눔글꼴 라이선스 안내](https://help.naver.com/service/30016/contents/18088?lang=ko&osType=PC)의 저작권·예약 이름 고지, SIL OFL 1.1 영문 전문을 함께 포함했습니다. [공식 나눔휴먼 소개](https://m-hangeul.naver.com/font/detail/NanumHuman)에서 오픈 라이선스 글꼴임을 확인했습니다. [공식 ZIP](https://hangeul.naver.com/hangeul_static/webfont/zips/NanumHuman.zip)에는 별도 이용허락문 파일이 없어 위 공식 고지와 영문 전문을 구성했습니다.

라이선스 원문과 저작권 고지를 임의로 삭제하거나 폰트 자체를 별도 판매하지 마세요. 로고·아이콘의 권리는 이 폰트 라이선스의 적용 대상이 아닙니다.
